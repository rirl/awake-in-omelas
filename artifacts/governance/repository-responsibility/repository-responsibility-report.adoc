== Scope

This assessment applies only to the active
`awake-in-omelas` repository.

The assessment excludes the confidential operator-state archive
and does not modify any repository structure.

== Objectives

The objectives of this assessment are:

* inventory the repository
* classify repository responsibilities
* determine authoritative ownership
* identify architectural dependencies
* identify repository boundary risks
* recommend governed promotions
* recommend governed removals
* determine whether the repository refactor following Breakpoint Beta is complete

== Governing Principles

This assessment shall be conducted according to the following principles:

. Inventory before classification.
. Classification before recommendations.
. Recommendations only after the complete inventory has been assessed.
. Repository responsibility shall be determined by long-term architectural ownership rather than current location.
. Historical evidence shall not be relocated without preserving provenance.
. Reusable implementation shall be distinguished from project-specific implementation.
. Confidential operator-state shall remain outside Git-managed repositories.
. Uncertainty shall be explicitly recorded rather than resolved through assumption.

== Assessment Method

The assessment shall proceed in the following order:

. Repository inventory
. Responsibility classification
. Dependency analysis
. Risk assessment
. Repository boundary assessment
. Promotion recommendations
. Removal recommendations
. Final architectural assessment

== Repository Responsibility Model

Each significant artifact shall be assigned one primary responsibility.

[cols="1,4"]
|===
|Classification |Meaning

|Awake in Omelas
|The artifact's continuing responsibility belongs to the Omelas project.

|Governed MCP Runtime
|The artifact represents reusable governed execution capabilities.

|Breakpoint Preservation
|The artifact primarily preserves historical engineering evidence.

|Operator State
|The artifact represents confidential or mutable operational state and shall not reside in Git.

|Obsolete
|The artifact no longer has an architectural responsibility.

|Uncertain
|Insufficient evidence exists to determine authoritative responsibility.
|===

== Assessment Deliverables

The completed assessment shall produce:

* Repository Responsibility Report
* Responsibility Matrix
* Recommended Promotions
* Recommended Removals
* Repository Boundary Diagram
* Final Repository Responsibility Assessment
