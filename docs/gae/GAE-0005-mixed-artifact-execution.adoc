== Objective

artifact operations:

* update one existing artifact;
* create one new artifact.

The test evaluated whether mixed create/update behavior could remain bounded
by artifact-specific contracts while preserving independent human admission.

The existing lesson artifact was read before modification. The new observation
artifact was created as part of the same bounded governed operation. Both

== Conformance Determination

GAE-0005 conformed to its objective and permitted-change contract. The mixed
create/update operation remained bounded to the named artifacts, preserved the
artifact-specific constraints, and left independent Git diff review, human
