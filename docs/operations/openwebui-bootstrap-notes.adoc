== Docker Containers

=== Open WebUI

[source,bash]
----
docker run -d \
  --name open-webui \
  --restart unless-stopped \
  -p 3000:8080 \
  -v /home/landonr/projects/openwebui/data:/app/backend/data \
  ghcr.io/open-webui/open-webui:main
----

Start:

[source,bash]
----
docker start open-webui
----

Stop:

[source,bash]
----
docker stop open-webui
----

Logs:

[source,bash]
----
docker logs --tail 100 open-webui
----

== MCP Filesystem Server

Read-only test command:

[source,bash]
----
docker run --rm -it \
  --name Omelas-MCP-RO \
  --read-only \
  --security-opt no-new-privileges:true \
  -p 127.0.0.1:8765:8000 \
  -v /home/landonr/projects/awake-in-omelas:/workspace/omelas:ro \
  mcp/filesystem:latest \
  /workspace/omelas
----

Observed output:

[source,text]
----
Secure MCP Filesystem Server running on stdio
Allowed directories: [ '/workspace/omelas' ]
----

Important: this MCP server uses stdio. Open WebUI cannot use it directly as an HTTP endpoint.

== Next Operational Step
